# AI native 社区

奥特大出生的公开 AI 实践与共建入口。在线站点：[AI native 社区](https://api.190675.xyz/ai-hub/)。

首页保留社区定位、全局搜索与六个入口，内容按独立页面组织：网站导航、设计资源、实践指南、效率工具箱、共建、从一步开始，另有提示词工坊和视频索引。暖白底、炭黑文字和陶土色强调，共用设计 token；支持移动端、键盘与减少动态效果偏好。

## 公开内容

- 69 个去重网站、10 个功能分类；原有 51 个网站的 ID、URL 与字段保持不变，新增 18 个设计资源。设计页包含既有 Eyecandy，共 19 个资源。
- 55 张公开知识卡，分为六个主题。
- 9 个效率工具卡。仅 PixPin 与 ManicTime 标为本人推荐；其余分别说明已观察或待体验。
- 9 条已确认属于本人的邀请链接，与安全官网并列展示，并披露可能获得平台奖励。现金返佣、比例、提现、到账均未验证，不作承诺。

历史浏览和收藏仅用于发现线索，不等于本人背书。第三方模型探针不能证明模型真实身份，请勿向不可信服务提交生产 API 密钥。价格、权限、可用性和授权范围以平台当前规则为准。

## 本地构建

需要 Node.js 24，无第三方依赖。

```sh
npm run build
npm run check
npm start
```

启动命令输出随机本地端口，访问其 `/ai-hub/`。`data/` 只保存审核后的公开数据；`source/` 和渲染器生成 `public/` 及 `assets.mjs`。Cloudflare Worker 仅提供列明的 14 个资源，其他路径返回 404，不使用数据库或密钥绑定。

检查覆盖分类、搜索数据、原有 51 条完整记录、9 条邀请 URL、111 个旧锚点、内部链接、路径和请求方法隔离、公开隐私边界及密钥模式。旧根路径 hash、topic/siteCategory 深链会转到对应独立页面。
